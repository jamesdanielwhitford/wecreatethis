### 3. Regenerated all four PDFs (PR #21, `194be05`)

The checked-in PDFs predated everything above - still "3 years", still the single-HN claim
with the 1.5k+ figure, none of the new articles. Anything attached to an application would
have contradicted the live site.

No generator script existed in the repo (commit `5af3269`, "Remove print buttons from PDFs
via JS DOM removal", did it ad hoc). Rebuilt the flow: `python3 -m http.server` + headless
Chrome `--print-to-pdf`, script kept at
`scratchpad/mkpdf.sh` (temporary - **not** in the repo).

**Gotcha:** the first render included the Print / Download PDF buttons. The `.no-print` rule
lives inside a `@media print` block, which `--print-to-pdf` does not reliably apply. Fix is
to inject an unconditional `.no-print{display:none !important}` into a temp copy before
rendering - effectively what `5af3269` did with DOM removal.

**Verification gotcha:** a Python text-extraction check reported *every* search string as
absent, including ones certainly present. The text is font-encoded in streams it could not
decode. That check is useless here - **verify these PDFs by reading the rendered pages**,
which is what was done.

### 4. Fixed a print layout bug (PR #22, `a7d6d52`)

James reported `cv-fde`'s PDF had a huge gap: page 1 ended after Profile, everything else
started on page 2.

**Cause:** the `Experience` `h2` has `break-after: avoid` and `.job-entry` had
`break-inside: avoid`. The first FDE entry has **nine** bullets, which no longer fit in the
space left on page 1, so Chrome moved the heading and the entire entry to page 2 rather than
splitting either. `cv/` was unaffected because its first entry has **eight** bullets and
still fits.

**Fix:** allow `.job-entry` to split across pages. `.project-card`, `li` and `h2` keep
`break-inside: avoid`, so cards and bullets stay whole and headings stay with their content.

Page 1 now fills correctly. The document remains 3 pages, with the last two featured cards on
a short page 3 - **James chose to keep this as-is** over tightening spacing or cutting cards.
