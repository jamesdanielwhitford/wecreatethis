# Session 008 - 2026-07-17

## Summary

Built and shipped **Bird Bingo**, a new standalone app separate from Birdle: daily 3x3 bingo card plus unlimited practice mode (3x3/4x4/5x5), cards built from real nearby eBird sightings rather than a fixed species list, own life list, bird detail pages with description/call/sighting logging. Preceded by a throwaway test harness (`birdle-tests/garden-birds.html`, not committed) comparing several "birds likely in your garden" ranking calculations against real eBird data before picking one. Live in prod on `main`.

## Decisions

- **Calculation method**: nearby observations within a tight 8km radius of the exact GPS point, ranked by checklist frequency (not raw API order, not a wide 50km radius). Chosen after hand-comparing ~9 methods in the test harness — tight radius biases toward birds actually around the house rather than rarities visiting birders travel to chase, which the wide default radius surfaces.
- **Fully separate data**: own IndexedDB (`bird-bingo-db`), own life list, no sharing with Birdle's `birdle-db`.
- **Daily card is personal, not global**: seeded by `date + rounded lat/lng` (same LCG approach as Hardle's daily word), locked for the day, regenerated only if location changes beyond GPS-jitter tolerance (~0.005°/~500m).
- **Practice cards are unseeded/live**: fresh frequency-ranked pull each time, any size, location prompted per card (default to saved location or capture new).
- **Hard mode fallback**: excludes life-list species from the pool; tops up with next-most-frequent already-seen species if too few unseen birds qualify, rather than leaving cells empty.
- **Marking is fully derived, never manual**: a square is "found" purely because a real sighting is logged for that species dated on/after the card's `createdAt` — recomputed live from `getAllSightings()` on every render, so deleting a sighting correctly un-marks squares and un-lifers a bird with no separate cascade code needed.
- **Celebrations are CSS-only**, matching Birdle's existing pulse/glow style — no new animation library.
- **Grid always shows image + name** (no toggle), unlike Birdle's bingo page.
